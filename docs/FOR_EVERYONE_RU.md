## Что это, одним абзацем

Это программа, которая поднимает небольшую частную сеть из нескольких узлов и ведёт общую книгу записей. Часть написана на Python (управление, API, проверки), тяжёлая часть — на Rust (криптография, хранение, исполнение). Сеть можно запустить у себя на компьютере и открыть местный сайт-обозреватель. Это не биржа, не приложение «купи монету» и не публичная сеть, в которую уже ходят посторонние люди.

Раньше репозиторий назывался Absolute Blockchain Ultimate Hybrid. Имя на GitHub сейчас `dup-protocol`.

## Что можно сказать вслух

- Автор собрал гибридный узел блокчейна: Python снаружи, Rust внутри.
- Есть автоматические тесты на GitHub и локальная сеть из трёх узлов.
- Деньги внутри считаются целыми числами, не дробями. Это защита от ошибок округления.
- Мост в другие сети выключен.
- Лицензия MIT: код можно читать и проверять. Авторство при этом остаётся за автором.

## Чего нельзя говорить

- «Монета уже торгуется» или «это публичный mainnet». Нет.
- «Проект прошёл аудит фирмы». Нет. Чеклист внешней проверки закрыт на 6 пунктов из 8. Не хватает пентеста и PDF сторонней фирмы.
- «Два репозитория — это одно и то же». Нет. Второй репозиторий — полигон для опытов. Его прогоны не доказывают этот репозиторий.
- «Товарный знак в Беларуси уже зарегистрирован». Нет. Есть только подготовка заявки.

## Что увидит человек, если запустит узел

| Адрес | Что это |
|---|---|
| http://localhost:8080 | Обычная страница в браузере. Обозреватель. |
| http://localhost:8545 | Не страница. Сюда программы шлют запросы. В браузере будет ошибка. На рабочем профиле нужен ключ. |
| ws://localhost:8766 | Канал для программ, не вкладка браузера. |

Локальный узел на порту 8080 — не публичная сеть из трёх машин. Трёхузловая сеть поднимается отдельно, в Docker.

## Как устроено, без номеров документов

1. Снаружи — сайт, обычные запросы и канал для программ.
2. Дальше Python решает, какой кусок работы кому отдать.
3. Rust считает криптографию, корни состояния и хранит данные.
4. Узлы обмениваются сообщениями. Сейчас на рабочей конфигурации это rust-libp2p. Старая замороженная метка `v1.3.1339-tip-v2-industrial` описывает более ранний вариант: TCP и TLS.
5. Мост, торговля NFT как в Ethereum, оракулы и «шарды» в промышленном профиле выключены. Код лабораторий для них есть, переключатели на боевом профиле стоят в положении «выкл».

Long-Range (защита от очень старой подмены истории) в коде есть как лаборатория. На промышленном профиле переключатель выключен. Это не отдельный вид криптографии BLS: BLS здесь не реализован.

## Что уже проверяли

- Автоматические тесты и сборка на GitHub.
- Локальный самотест, включая режим Max: он поднимает один узел на этом компьютере и отдельную короткую проверку связи. Это не суточный прогон сети.
- Длинный прогон сети 15–17 октября 2026 (около 48 часов, без жёстких сбоев) лежит в папке `docs/evidence/runs/pin-libp2p-strict-48h`. Это доказательство устойчивости той сборки, не запуск публичной сети. Номер коммита в начале того прогона был с незакоммиченными правками. Отдельную чистую метку под этот прогон не ставили.

## Рекрутеру: как прочитать репозиторий за десять минут

1. [README](../README.md) — первая страница. Бейджи тестов должны быть зелёными. Зелёный бейдж значит «тесты прошли», не «сеть запущена для всех».
2. Этот файл — границы проекта.
3. [LICENSE](../LICENSE) — MIT. [CITATION.cff](../CITATION.cff) — как цитировать автора.
4. Папки `consensus`, `network`, `crypto`, `storage`, `native/abs_native` — ядро. `api` — вход снаружи. `docs/adr` — короткие решения «почему так», их не обязательно читать все.
5. `tests/` и `.github/workflows` — как проект проверяет сам себя.

В резюме корректно: «гибридный L1-узел Python + Rust, приватная mesh-сеть, доказательства прогонов в репозитории, внешний аудит ещё не сдан».  
Некорректно: «запустил mainnet», «прошёл аудит», «выпустил листинговую монету».
