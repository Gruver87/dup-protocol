This document helps you (or a Belarus patent attorney / патентный поверенный) file

Fees are set in **базовые величины (БВ)** in the Tax Code of Belarus. Recalculate
with the **current** БВ and NCIP calculator before paying — do not rely on stale
BYN amounts in secondary articles.

Illustrative structure (verify on NCIP / НК РБ before payment):

| Stage | Typical rate (БВ) | Note |
|-------|-------------------|------|
| Filing + formal exam | ~10 БВ (+ ~5 БВ per class above 1st) | Often −15% for e-filing |
| Substantive exam of the mark | ~28 БВ | After formal stage |
| Registration + certificate | ~19 БВ | After positive decision |

One class often totals on the order of **~57 БВ** in state fees alone (plus attorney
if used). Confirm live rates before transfer.

## Suggested Nice classes (МКТУ) — draft for attorney review

Blockchain / software / open-source protocol use is usually **services + software**.
Typical starting set (trim to budget; each class costs more):

| Class | Why for DUP |
|-------|-------------|
| **9** | Software, downloadable / recorded computer programs, cryptographic software |
| **42** | SaaS, software as a service, R&D, scientific/tech services, hosting, design of software |
| **36** | Optional: financial / crypto-related services — **only** if you actually offer them under the mark; higher scrutiny |
| **41** | Optional: education / publication of materials / training |

**Start lean:** classes **9 + 42** for both marks A and B unless counsel advises otherwise.

Draft goods/services wording (Russian/English — attorney will normalize to МКТУ N edition):

**Class 9 (sample):**  
Computer software; downloadable computer software for blockchain, cryptography,
peer-to-peer networking, and distributed ledger protocols; electronic publications
(downloadable) in the field of computer technology.

**Class 42 (sample):**  
Design and development of computer software; software as a service [SaaS];
scientific and technological research in the field of blockchain and cryptography;
hosting of computer websites; consultancy in the field of computer software;
provision of non-downloadable software for distributed ledger / protocol operation
(lab and production mesh tooling).

Do **not** claim “mainnet banking” or regulated financial services unless true.
